💾 Backup & pindah perangkat

Bawa memori Sherly, riwayat chat, prompt tersimpan, kalender publikasi, pengaturan non-rahasia, branding, dan Character Vault ke PC atau HP lain lewat satu file JSON.

Timpa akan mengganti data FlowPrompt yang termasuk backup. Gabungkan akan mempertahankan data yang ada dan menambahkan catatan/entri dari backup bila memungkinkan.
Backup tidak menyertakan API key demi keamanan. Setelah pindah perangkat, masukkan API key lagi di Pengaturan.
Simpan file backup di tempat pribadi. File ini bisa berisi riwayat percakapan dan referensi karakter. Jangan unggah ke tempat publik. Sebelum memulihkan, buat backup dari perangkat tujuan jika ada data yang masih dibutuhkan.
